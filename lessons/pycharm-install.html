آموزش کامل نصب PyCharm

⏱️ زمان مطالعه: ۱۰ دقیقه | 📅 آخرین بروزرسانی: ۱۴۰۵

PyCharm چیست؟

PyCharm یک محیط توسعه یکپارچه (IDE) اختصاصی برای زبان پایتون است که توسط شرکت JetBrains ساخته شده. بر خلاف VS Code که یک ویرایشگر متن همه‌منظوره با افزونه پایتون است، پایچارم از ابتدا مخصوص پایتون طراحی شده و ابزارهای پیشرفته‌تری مثل تشخیص خودکار خطا، ریفکتور کردن هوشمند کد، دیباگر گرافیکی قدرتمند و مدیریت پروژه حرفه‌ای را به‌صورت پیش‌فرض دارد.

💡 چرا پایچارم را امتحان کنیم؟
  • تشخیص خطا و پیشنهاد تکمیل کد بسیار دقیق‌تر و هوشمندتر
  • دیباگر گرافیکی حرفه‌ای برای پیدا کردن باگ‌ها به‌صورت مرحله‌به‌مرحله
  • مدیریت داخلی محیط‌های مجازی (venv) و پکیج‌ها
  • ادغام کامل با Git و ابزارهای کنترل نسخه
  • پشتیبانی داخلی از Jupyter Notebook
⚠️ نکته مهم درباره نسخه‌ها: تا قبل از سال ۲۰۲۵، پایچارم دو نسخه جدا داشت: Community (رایگان و متن‌باز) و Professional (پولی). از نسخه ۲۰۲۵.۱ به بعد، JetBrains این دو را در یک محصول واحد به نام «PyCharm» ادغام کرده است. یعنی دیگر نصب‌کننده جداگانه‌ای با نام Community وجود ندارد؛ همه یک نسخه را نصب می‌کنند.

💳 نسخه رایگان در مقابل Pro

در نسخه یکپارچه فعلی پایچارم، وضعیت به این شکل است:

🆓 نسخه رایگان (Core)

  • همیشه و برای همیشه رایگان است
  • شامل تمام امکانات اصلی پایتون
  • شامل پشتیبانی از Jupyter Notebook
  • دیباگر، Git، تست‌ران و ریفکتورینگ

⭐ اشتراک Pro

  • پشتیبانی کامل از Django و Flask
  • ابزارهای پایگاه داده و SQL
  • توسعه ریموت (Remote Development)
  • ابزارهای علمی و تحلیل داده پیشرفته
ℹ️ نحوه کار دوره آزمایشی: با نصب پایچارم، به‌صورت خودکار یک دوره آزمایشی ۳۰ روزه رایگان از امکانات Pro برایتان فعال می‌شود. بعد از پایان این ۳۰ روز، دو راه دارید: خرید اشتراک Pro، یا ادامه استفاده رایگان و نامحدود از نسخه Core. برای یادگیری پایتون در حد این دوره، نسخه رایگان کاملاً کافی است و هیچ نیازی به خرید اشتراک ندارید.

📋 پیش‌نیازهای سیستم

پایچارم نسبت به VS Code سنگین‌تر است، پس قبل از نصب سیستم خود را بررسی کنید:

💻 ویندوز

  • ویندوز ۱۰ یا ۱۱ (پردازنده x86_64 یا arm64)
  • حداقل ۸ گیگابایت رم (۳ گیگ برای خود IDE)
  • ۱۰ گیگابایت فضای خالی دیسک

🍎 مک

  • macOS نسخه ۱۵ یا ۲۶
  • حداقل ۸ گیگابایت رم
  • ۱۰ گیگابایت فضای خالی دیسک

🐧 لینوکس

  • Ubuntu 24.04+ / Fedora 43+ / Debian 13+
  • حداقل ۸ گیگابایت رم
  • ۱۰ گیگابایت فضای خالی دیسک
ℹ️ توجه: برای اجرای پایچارم نیازی به نصب جاوا ندارید؛ یک نسخه از JetBrains Runtime به‌صورت داخلی همراه IDE نصب می‌شود.

🧰 روش پیشنهادی: نصب با JetBrains Toolbox App

JetBrains برای نصب همه محصولاتش (از جمله پایچارم) استفاده از برنامه Toolbox App را توصیه می‌کند. این برنامه به‌صورت خودکار به‌روزرسانی‌ها را مدیریت می‌کند، امکان نصب چند نسخه هم‌زمان را می‌دهد و حذف برنامه را بسیار ساده‌تر می‌کند.

  1. دانلود Toolbox App:

    به آدرس jetbrains.com/toolbox/app بروید و نسخه سیستم‌عامل خود را دانلود کنید.

    ⚠️ نکته مهم: همیشه از سایت رسمی jetbrains.com دانلود کنید تا از دریافت نسخه‌های جعلی یا آلوده جلوگیری شود.
  2. نصب Toolbox App:

    فایل دانلود شده را اجرا کنید و مراحل نصب‌کننده را دنبال کنید (در ویندوز فایل exe.، در مک فایل dmg. و در لینوکس فایل tar.gz.).

  3. انتخاب و نصب PyCharm:

    بعد از اجرای Toolbox App، آیکون آن را در نوار اعلانات (ویندوز/لینوکس) یا نوار منو (مک) پیدا کنید. لیست محصولات JetBrains باز می‌شود؛ روی PyCharm کلیک کرده و دکمه Install را بزنید.

  4. ورود به حساب کاربری (اختیاری):

    اگر لایسنس Pro دارید، با ورود به حساب JetBrains خود، لایسنس به‌صورت خودکار فعال می‌شود. برای استفاده رایگان، می‌توانید این مرحله را رد کنید.

✅ چرا Toolbox App بهتر است؟

هر وقت نسخه جدید پایچارم منتشر شود، Toolbox App به شما اطلاع می‌دهد و به‌روزرسانی تنها با یک کلیک انجام می‌شود. همچنین اگر بعداً بخواهید IDE دیگری از JetBrains (مثل WebStorm) نصب کنید، همه از یک‌جا مدیریت می‌شوند.

📦 روش دوم: نصب مستقیم (Standalone)

اگر ترجیح می‌دهید مستقیماً نصب‌کننده پایچارم را دانلود کنید (بدون Toolbox App)، این روش هم کاملاً معتبر است.

  1. ورود به صفحه دانلود:

    به آدرس jetbrains.com/pycharm/download بروید. سیستم‌عامل شما (ویندوز، مک یا لینوکس) به‌صورت خودکار تشخیص داده می‌شود.

  2. دانلود نصب‌کننده:

    روی دکمه Download کلیک کنید. برای ویندوز فایل exe. و برای مک، بسته به نوع پردازنده (Intel یا Apple Silicon)، فایل dmg. مناسب را انتخاب کنید.

  3. اجرای نصب‌کننده (ویندوز):

    فایل دانلود شده را اجرا کنید. در مراحل نصب‌کننده به این گزینه‌ها دقت کنید:

    • 64-bit launcher: ساخت میانبر روی دسکتاپ
    • .py: باز شدن فایل‌های پایتون به‌صورت پیش‌فرض با پایچارم
    • Add launchers dir to the PATH: امکان اجرای پایچارم از خط فرمان

    سپس روی Install کلیک کنید و صبر کنید تا نصب کامل شود.

  4. اجرای نصب‌کننده (مک):

    فایل dmg. را باز کنید و آیکون PyCharm را به داخل پوشه Applications بکشید.

  5. اجرای نصب‌کننده (لینوکس):

    فایل فشرده tar.gz. را در مسیر دلخواه (طبق استاندارد FHS معمولاً opt/) استخراج کنید:

    bash 
    sudo tar xzf pycharm-*.tar.gz -C /opt/
cd /opt/pycharm-*/bin
./pycharm.sh

    همچنین می‌توانید پایچارم را از طریق snap نصب کنید:

    sudo snap install pycharm --classic

🚀 اجرای پایچارم برای اولین بار

  1. باز کردن برنامه:

    در ویندوز از Start Menu یا میانبر دسکتاپ، در مک از پوشه Applications یا Launchpad، و در لینوکس با اجرای اسکریپت pycharm.sh، برنامه را باز کنید.

  2. وارد کردن تنظیمات قبلی (اختیاری):

    در اولین اجرا، پایچارم می‌پرسد آیا می‌خواهید تنظیمات یک IDE دیگر (مثلاً VS Code) را وارد کنید یا خیر. برای شروع تازه، می‌توانید این مرحله را رد کنید.

  3. انتخاب تم ظاهری:

    در صفحه خوش‌آمدگویی (Welcome Screen)، می‌توانید تم روشن یا تیره و چیدمان کیبورد دلخواه خود را انتخاب کنید.

  4. ساخت پروژه جدید:

    روی گزینه New Project کلیک کنید. یک مسیر برای پروژه انتخاب کرده و مطمئن شوید گزینه Create a main.py welcome script فعال است.

  5. تنظیم مفسر پایتون (Interpreter):

    پایچارم به‌صورت خودکار پایتون نصب‌شده روی سیستم شما را پیدا می‌کند و پیشنهاد می‌دهد یک محیط مجازی (venv) جدید برای این پروژه بسازد. این گزینه پیش‌فرض را بپذیرید؛ این کار باعث می‌شود پکیج‌های هر پروژه از پروژه‌های دیگر جدا بمانند.

    اگر بعداً خواستید مفسر را عوض کنید: Ctrl+Alt+S (ویندوز/لینوکس) یا Cmd+, (مک) را بزنید و به مسیر Project → Python Interpreter بروید.

👋 اولین برنامه: Hello World در پایچارم

حالا بیایید همان برنامه ساده درس اول را این‌بار داخل پایچارم بنویسیم:

  1. ساخت فایل جدید:

    روی نام پوشه پروژه در پنل سمت راست (Project) راست‌کلیک کنید و مسیر New → Python File را انتخاب کنید. نام فایل را hello بگذارید (پایچارم خودش پسوند py. را اضافه می‌کند).

  2. نوشتن کد:

    این کد را در فایل بنویسید. همان‌طور که تایپ می‌کنید، پایچارم پیشنهادهای تکمیل کد را نمایش می‌دهد:

    hello.py 
    # اولین برنامه من در پایچارم
print("Hello, World!")
print("به دنیای برنامه‌نویسی خوش آمدید!")
  3. اجرای فایل:

    روی فلش سبز رنگ کنار خط اول کد، یا در گوشه بالا-راست پنجره کلیک کنید. همچنین می‌توانید کلید میانبر Shift+F10 (ویندوز/لینوکس) یا Ctrl+R (مک) را بزنید.

    خروجی در پنل Run در پایین صفحه نمایش داده می‌شود:

    Hello, World!
به دنیای برنامه‌نویسی خوش آمدید!
✅ چند نکته کاربردی برای شروع:
  • برای اجرای دیباگر به‌جای اجرای عادی، از دکمه سبز رنگ کنار فلش اجرا (شکل حشره 🐛) استفاده کنید.
  • برای دیدن همه میانبرهای صفحه‌کلید: Help → Keymap Reference
  • دکمه Learn در صفحه خوش‌آمدگویی، یک آموزش تعاملی داخل خود IDE برایتان باز می‌کند.

🔧 عیب‌یابی مشکلات رایج

❌ نصب‌کننده اجرا نمی‌شود یا کند است

علت: سیستم به حداقل نیازمندی‌ها (به‌خصوص ۸ گیگ رم) نمی‌رسد.

راه‌حل: برنامه‌های سنگین دیگر را ببندید. اگر باز هم کند بود، از VS Code به‌عنوان جایگزین سبک‌تر استفاده کنید.

❌ پایچارم مفسر پایتون را پیدا نمی‌کند

علت: پایتون هنوز روی سیستم نصب نشده یا در مسیر استاندارد نیست.

راه‌حل: ابتدا طبق درس اول پایتون را نصب کنید، سپس در پایچارم به Project → Python Interpreter → Add Interpreter بروید و مسیر نصب پایتون را دستی معرفی کنید.

❌ پیام "Pro trial expired" نمایش داده می‌شود

علت: دوره آزمایشی ۳۰ روزه Pro تمام شده است.

راه‌حل: نگران نباشید؛ کافی است گزینه Keep using Community features for free (یا مشابه آن) را انتخاب کنید تا بدون محدودیت به استفاده از نسخه رایگان ادامه دهید.

❌ در لینوکس با خطای پکیج‌های گرافیکی مواجه می‌شوم

علت: برخی وابستگی‌های گرافیکی نصب نیستند.

راه‌حل: پکیج‌های libxi6، libxrender1، libxtst6 و libfontconfig را نصب کنید:

sudo apt install libxi6 libxrender1 libxtst6 libfontconfig

⚖️ پایچارم یا VS Code؟

هیچ‌کدام «بهتر مطلق» نیستند؛ انتخاب به نیاز شما بستگی دارد:

💡 جمع‌بندی ساده:
  • VS Code را انتخاب کنید اگر: سیستم ضعیف‌تری دارید، به چند زبان برنامه‌نویسی هم‌زمان نیاز دارید، یا سبکی و سرعت راه‌اندازی برایتان مهم است.
  • PyCharm را انتخاب کنید اگر: فقط با پایتون کار می‌کنید، روی پروژه‌های بزرگ‌تر کار می‌کنید، یا به ابزارهای دیباگ و ریفکتور پیشرفته نیاز دارید.
  • برای شروعِ شروع (چند هفته اول یادگیری)، هر دو گزینه کاملاً مناسب هستند و می‌توانید بعداً هم بین آن‌ها جابه‌جا شوید.
