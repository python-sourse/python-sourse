پایتون چیست؟

پایتون یک زبان برنامه‌نویسی سطح بالا، تفسیری و همه‌منظوره است که در سال ۱۹۹۱ توسط گیدو ون روسوم ایجاد شد. نام این زبان از برنامه تلویزیونی «سیرک پرنده مانتی پایتون» گرفته شده است.

💡 چرا پایتون برای شروع عالی است؟
  • سینتکس ساده و خوانا (شبیه زبان انگلیسی)
  • جامعه بزرگ و منابع آموزشی فراوان
  • کاربرد در وب، هوش مصنوعی، علم داده و اتوماسیون
  • رایگان و متن‌باز

📋 پیش‌نیازهای سیستم

قبل از نصب، مطمئن شوید سیستم شما حداقل نیازمندی‌ها را دارد:

💻 ویندوز

  • ویندوز ۸.۱ یا بالاتر (۶۴-بیت توصیه می‌شود)
  • حداقل ۲ گیگابایت رم
  • ۵۰۰ مگابایت فضای خالی

🍎 مک

  • macOS 10.9 (Mavericks) یا بالاتر
  • حداقل ۲ گیگابایت رم
  • ۵۰۰ مگابایت فضای خالی

🐧 لینوکس

  • Ubuntu 18.04+ / Fedora 30+ / Debian 10+
  • حداقل ۱ گیگابایت رم
  • ۳۰ مگابایت فضای خالی

🪟 نصب روی ویندوز (مرحله به مرحله)

  1. دانلود نصب‌کننده:

    به سایت رسمی پایتون بروید: python.org/downloads

    روی دکمه زرد رنگ "Download Python 3.x.x" کلیک کنید (آخرین نسخه پایدار).

    ⚠️ نکته مهم: همیشه از سایت رسمی دانلود کنید. از سایت‌های متفرقه ممکن است بدافزار دریافت کنید.
  2. اجرای فایل دانلود شده:

    فایل python-3.x.x-amd64.exe را اجرا کنید.

    🚨 حیاتی‌ترین مرحله: قبل از کلیک روی "Install Now"، حتماً تیک گزینه زیر را بزنید:
    ☑ Add Python 3.x to PATH
    بدون این تیک، نمی‌توانید پایتون را در Command Prompt اجرا کنید!
  3. انتخاب نوع نصب:

    دو گزینه دارید:

    • Install Now: نصب سریع با تنظیمات پیش‌فرض (توصیه شده برای مبتدیان)
    • Customize installation: انتخاب ماژول‌ها و مسیر نصب (برای کاربران پیشرفته)

    برای شروع، Install Now را انتخاب کنید.

  4. صبر برای اتمام نصب:

    فرآیند نصب ۲-۵ دقیقه طول می‌کشد. پنجره‌ای با پیام "Setup was successful" نمایش داده می‌شود.

  5. غیرفعال کردن محدودیت طول مسیر (اختیاری اما توصیه شده):

    اگر پیام "Disable path length limit" دیدید، روی آن کلیک کنید. این کار محدودیت ۲۶۰ کاراکتری ویندوز را برمی‌دارد.

  6. بررسی نصب:

    کلیدهای Win + R را بزنید، بنویسید cmd و Enter کنید.

    در Command Prompt تایپ کنید:

    cmd 
    python --version

    اگر خروجی شبیه Python 3.12.0 دیدید، تبریک! نصب موفق بوده است. 🎉

✅ تست نهایی ویندوز:

در همان Command Prompt تایپ کنید:

python -c "print('سلام پایتون!')"

اگر عبارت "سلام پایتون!" نمایش داده شد، همه چیز عالی کار می‌کند.

🍎 نصب روی مک (مرحله به مرحله)

ℹ️ توجه: مک‌های جدید معمولاً پایتون ۲.۷ قدیمی دارند. ما پایتون ۳ را نصب می‌کنیم که کاملاً جداگانه است.
  1. روش اول: دانلود مستقیم (ساده‌ترین)

    به python.org/downloads/macos بروید.

    فایل macOS 64-bit universal2 installer را دانلود کنید.

  2. اجرای نصب‌کننده:

    فایل .pkg را باز کنید و مراحل را دنبال کنید:

    • Continue → Continue → Agree
    • Install (رمز عبور مدیر سیستم لازم است)
    • Close پس از اتمام
  3. روش دوم: Homebrew (توصیه شده برای توسعه‌دهندگان)

    اگر Homebrew ندارید، ابتدا Terminal را باز کنید و این دستور را بزنید:

    terminal 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    سپس پایتون را نصب کنید:

    brew install python
  4. بررسی نصب:

    Terminal را باز کنید (Command + Space → تایپ "Terminal") و بنویسید:

    python3 --version
    ⚠️ نکته مک: در مک باید از python3 استفاده کنید، نه python. چون python ممکن است به نسخه قدیمی ۲.۷ اشاره کند.
  5. بررسی pip (مدیر بسته): 
    pip3 --version

    pip ابزار نصب کتابخانه‌های پایتون است. باید همراه پایتون نصب شده باشد.

🐧 نصب روی لینوکس (مرحله به مرحله)

ℹ️ توجه: اکثر توزیع‌های لینوکس پایتون ۳ را از پیش نصب دارند. ابتدا بررسی کنید!
  1. بررسی نسخه فعلی:

    ترمینال را باز کنید (Ctrl+Alt+T) و بنویسید:

    python3 --version

    اگر نسخه ۳.۸ یا بالاتر دیدید، نیازی به نصب نیست!

  2. Ubuntu / Debian:
    bash 
    sudo apt update
sudo apt install python3 python3-pip python3-venv
  3. Fedora: 
    sudo dnf install python3 python3-pip
  4. Arch Linux: 
    sudo pacman -S python python-pip
  5. نصب آخرین نسخه (اختیاری):

    اگر نیاز به آخرین نسخه دارید (مثلاً ۳.۱۲) و مخازن توزیع شما قدیمی است:

    # Ubuntu PPA
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.12
  6. بررسی نهایی: 
    python3 --version
pip3 --version

📝 نصب ویرایشگر کد (VS Code)

برای نوشتن کد پایتون، به یک ویرایشگر متن نیاز دارید. Visual Studio Code بهترین گزینه رایگان است:

  1. دانلود VS Code:

    به code.visualstudio.com بروید و نسخه مناسب سیستم خود را دانلود کنید.

  2. نصب افزونه پایتون:

    بعد از نصب VS Code:

    • روی آیکون Extensions در نوار کناری کلیک کنید (یا Ctrl+Shift+X)
    • جستجو کنید: Python
    • افزونه رسمی Microsoft را نصب کنید (با آیکون آبی پایتون)
  3. تنظیم مفسر پایتون:

    کلیدهای Ctrl+Shift+P (ویندوز/لینوکس) یا Cmd+Shift+P (مک) را بزنید.

    تایپ کنید: Python: Select Interpreter

    مسیر پایتون نصب شده را انتخاب کنید.

✅ جایگزین‌های VS Code:
  • PyCharm Community: IDE اختصاصی پایتون (رایگان) — آموزش کامل نصب پایچارم را اینجا ببینید ←
  • Sublime Text: سبک و سریع
  • Thonny: مخصوص مبتدیان (همراه پایتون نصب می‌شود)

🚀 اولین برنامه: Hello World

حالا که همه چیز نصب شد، اولین برنامه پایتون خود را بنویسید!

  1. روش ۱: تعاملی (سریع‌ترین)

    ترمینال/Command Prompt را باز کنید و بنویسید:

    python

    وارد محیط تعاملی پایتون می‌شوید (با علامت >>>). حالا بنویسید:

    >>> print("Hello, World!")
Hello, World!
>>> exit()
  2. روش ۲: فایل اسکریپت (روش واقعی)

    یک فایل جدید در VS Code بسازید و نام آن را hello.py بگذارید.

    این کد را داخلش بنویسید:

    hello.py 
    # اولین برنامه پایتون من
print("Hello, World!")
print("به دنیای برنامه‌نویسی خوش آمدید!")

    فایل را ذخیره کنید (Ctrl+S).

  3. اجرای فایل:

    در ترمینال VS Code (Terminal → New Terminal) بنویسید:

    python hello.py

    یا در مک/لینوکس:

    python3 hello.py

    خروجی:

    Hello, World!
به دنیای برنامه‌نویسی خوش آمدید!

🔧 عیب‌یابی مشکلات رایج

❌ خطای "'python' is not recognized"

علت: تیک "Add to PATH" هنگام نصب زده نشده.

راه‌حل: پایتون را دوباره نصب کنید و این بار تیک را بزنید. یا متغیر محیطی PATH را دستی تنظیم کنید.

❌ خطای "Permission denied" در لینوکس/مک

علت: عدم دسترسی اجرایی به فایل.

راه‌حل: از sudo استفاده کنید یا مجوز اجرا بدهید: chmod +x file.py

❌ pip کار نمی‌کند

علت: pip نصب نشده یا در PATH نیست.

راه‌حل: در ویندوز: python -m ensurepip --upgrade
در لینوکس: sudo apt install python3-pip

❌ نسخه پایتون قدیمی است

علت: نسخه سیستم‌عامل قدیمی است.

راه‌حل: از روش‌های ذکر شده در بخش‌های بالا برای نصب آخرین نسخه استفاده کنید.
