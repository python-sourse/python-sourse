🐍 داستان یک زبان متفاوت

سال ۱۹۸، گیدو ون روسوم، برنامه‌نویس هلندی، در تعطیلات کریسمس حوصله‌اش سر رفته بود. او تصمیم گرفت زبانی بسازد که:

«زبانی که کدنویسی با آن مثل نوشتن متن انگلیسی ساده باشد، نه مثل حل معادله ریاضی!»

— گیدو ون روسوم، خالق پایتون

نام «پایتون» هم از علاقه او به برنامه کمدی بریتانیایی Monty Python's Flying Circus گرفته شد — نه از مار پایتون! 🎭

💡 چرا پایتون بهترین انتخاب برای شروع است؟

✅ پایتون

print("سلام دنیا!")

یک خط، خوانا، بدون سمبول‌های عجیب

❌ زبان‌های دیگر (مثل Java)

public class Main {
  public static void main(String[] args) {
    System.out.println("سلام دنیا!");
  }
}

۵ خط، پر از کلمات کلیدی پیچیده
